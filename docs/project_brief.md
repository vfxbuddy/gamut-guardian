# Gamut Guardian

## Product Vision

Gamut Guardian is a gamified learning and reference platform for Nuke compositors working in ACES.

The product combines:

- Practical production reference
- Flashcard learning
- Scenario-based challenges
- Workflow puzzle solving
- Progression and achievements

The goal is to make learning ACES and color management feel engaging while remaining genuinely useful during production.

Users should be able to:

- Quickly look up answers
- Learn terminology
- Practice workflows
- Diagnose common mistakes
- Reinforce knowledge through gameplay

The app should feel like a professional compositor training simulator.

## Core Product Pillars

1. Learn
2. Practice
3. Reference
4. Progress

## Target Audience

Primary:

- Junior compositors
- Mid-level compositors
- Students learning Nuke
- Artists transitioning into ACES workflows

Secondary:

- Senior compositors needing quick reference
- Comp leads onboarding artists

## Core Game Loop

Learn a concept. Apply the concept. Earn XP. Unlock progress. Return tomorrow.

## Rank Progression

1. Runner
2. Junior Comp
3. Compositor
4. Senior Compositor
5. Lead Compositor
6. Color Sentinel
7. Gamut Guardian

## MVP Features

- Home Dashboard
- Flashcards
- Scenario Challenges
- Field Guide
- Glossary
- Answer Finder

## Future Features

- Workflow Builder
- Shot Rescue
- Challenge Packs
- Advanced Color Management Tracks

## Success Metric

A compositor should open Gamut Guardian and immediately think: "This looks fun."

After a few minutes: "This is actually useful."

After a few weeks: "I understand ACES better because of this."
