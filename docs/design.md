# Gamut Guardian Design System

## Visual Inspiration

Inspired by Balatro, trading card games, retro CRT displays, professional VFX tools, and modern premium SaaS products.

Do not directly copy Balatro. Use the inspiration to create a unique visual language.

## Design Goal

Create the feeling of: "A secret training terminal for compositors."

Not: "A documentation website."

## Mood

- Professional
- Cinematic
- Playful
- Mysterious
- Rewarding
- High-tech

## Color Palette

Backgrounds: near black, charcoal, dark graphite.

Primary accents: cyan and electric blue.

Secondary accents: violet and amber.

Special: subtle rainbow gradients inspired by ACES color management.

## Typography

Primary: modern sans-serif.

Secondary: retro pixel-inspired display font.

Use pixel font only for XP, levels, achievements, and counters.

## Card Design

Cards are the primary UI element.

Card types:

- Knowledge Cards
- Workflow Cards
- Challenge Cards
- Achievement Cards
- Glossary Cards

Card features:

- Rounded corners
- Soft shadows
- Glow effects
- Rarity indicators
- Hover interactions
- Flip animations

## Rarity System

- Common
- Uncommon
- Rare
- Epic
- Legendary

Visual treatment should increase with rarity.

## Motion

Use motion throughout the experience: card flips, XP gain animations, achievement unlocks, and progress updates.

Animations should feel satisfying but not distracting.

## Layout

Mobile-first. Cards should stack naturally. Desktop should feel like a command center.

## Imagery

Use mock production frames, fake film plates, fake CG renders, workflow diagrams, and node graph illustrations.

Do not use copyrighted film stills. All imagery should support learning.

## UI References

The app should feel like a blend of Balatro, Raycast, Linear, and ArtStation Learning, with a strong VFX identity.
