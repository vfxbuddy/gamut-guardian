# Codex Prompt

Read `project_brief.md` and `design.md` before making any implementation decisions.

Build the first playable MVP of Gamut Guardian.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Requirements

- Deployable on Vercel
- Mobile-first
- Responsive
- No backend
- No authentication
- No database

## Build These Pages First

1. Home Dashboard
2. Flashcards
3. Scenario Challenges
4. Field Guide
5. Glossary
6. Answer Finder

Content should come from local TypeScript or JSON data files.

Create reusable data structures for flashcards, topics, scenarios, achievements, and glossary terms.

Include starter content for ACEScg, IDTs, ODTs, Utility Linear sRGB, HDRIs, Viewer Transforms, EXR workflows, and common ACES mistakes.

## Visual Direction

- Card-centric UI
- Balatro-inspired presentation
- Retro-futuristic compositor training terminal
- Premium motion design
- Dark mode

## Priorities

1. Great visual design
2. Fun interaction
3. Educational clarity
4. Expandable architecture

The MVP should feel polished, memorable, and immediately useful to Nuke compositors learning ACES.
